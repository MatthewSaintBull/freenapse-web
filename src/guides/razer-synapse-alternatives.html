The fifth option: set it once, remove everything

The Viper V3 Pro keeps its settings in onboard memory. Whatever tool writes them, the mouse keeps working the same way afterwards with nothing installed, on Windows, Linux or a Mac. So a Mac user can configure the mouse once on a Windows PC with freenapse, or on Linux with OpenRazer, and never run anything on the Mac. What you give up is the software-side extras: battery in the tray, per-game switching, macros.

Questions

Is freenapse a Razer Synapse alternative for every Razer mouse?
No. It is verified on one mouse, the Viper V3 Pro, wired and on its dongle. Other Razer mice are detected and opened read-only; freenapse probe prints what they answer, and an issue or pull request with that output is how a mouse gets added.
What about Synapse 3?
Razer’s older app still supports the mouse, and reviewers have found it detected the Viper V3 Pro when Synapse 4 would not. It is still Razer’s software, with the account and the background services, and Razer is moving devices to Synapse 4.
Does OpenRazer work on Windows?
No, it is a Linux kernel driver. On Windows the choices are Razer’s own software, Synapse Web for the devices it supports, or freenapse for the Viper V3 Pro.

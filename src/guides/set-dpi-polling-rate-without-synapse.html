Set the Viper V3 Pro DPI and polling rate without Synapse

Both values live in the mouse’s onboard memory. Write them once with freenapse and they stay set with nothing running, on any PC.

Five commands, no installer

  1. Get freenapse.exe and quit Synapse

    Download freenapse {{version}}, one file of {{exe_size_mb}} MB, and put it anywhere. If Razer Synapse is installed, quit it from the tray first: while it runs in the background it rewrites the settings it thinks it owns within about fifteen seconds.

  2. Read what the mouse has stored

    freenapse status

    Prints the DPI stages, the active stage and the polling rate straight from the mouse. Keep moving the mouse while a command runs: the wireless Viper V3 Pro stops answering the dongle after a few seconds idle.

  3. Set the DPI

    freenapse dpi 1600                      # live DPI, 100 to 35000 in steps of 1
freenapse dpi 1600 800                  # independent X and Y
freenapse stages 2 400 800 1600 3200    # four stages, the second one active

    Up to five stages. The DPI button under the mouse cycles through them, with no software involved.

  4. Set the polling rate

    freenapse polling 4000

    Wired: 125, 500 or 1000 Hz. Through the dongle: 125 to 8000 Hz, where 4000 and 8000 need the HyperPolling dongle and use more battery. The rate is stored like everything else.

  5. Or use the window

    freenapse ui

    The Performance page has the same controls: a slider and a number box per stage, the active stage, independent X and Y, and the polling rate slider. There is no apply button; each control writes to the mouse the moment it changes and reads the value back.

What the mouse does with it

DPI stages
Stored in the mouse’s onboard profile as up to five stages plus the active one. The live DPI and the stage table are two separate settings in the mouse; freenapse status shows both.
Polling rate
One command to the dongle, or the classic command when wired. The tray app can raise the rate only while a game is in the foreground (polling.game_rate in the config) and lower it again when the game ends.
Afterwards
Close freenapse. The settings survive reboots and follow the mouse to any PC. The tray app only adds the battery icon, quick switching and per-game profiles.

Questions

Do I need Synapse installed at all?
No. freenapse talks to the standard Windows HID stack and needs no Razer driver or service. If Synapse is still installed, quit it; the uninstall guide covers removing it without losing anything.
The command printed “no answer”.
The mouse was asleep. Move it and run the command again. The tray app and the settings window keep the change pending and write it on their own when the mouse wakes.
Can the DPI be different per game?
Yes, with the tray app running: a profile per game sets a DPI stage, a polling rate and a button layout while that game is in the foreground. The games installed through Steam, Epic, GOG and the other launchers are listed on the Games page of the window.

Supported Razer mice

Which Razer mice freenapse {{version}} configures, and what it can set on each one. A verified mouse has been tested setting by setting on real hardware; every other one opens read-only until its owner tests it.

Add your mouse

Run freenapse probe with Synapse closed and paste the output into a “New mouse” issue. The probe only reads: it lists what the mouse answers to, every button code included. The next step is testing the writes on your mouse, with [device] allow_unverified = true in the config, and sending its row of src/device.rs. CONTRIBUTING.md has the steps; the DeathAdder V3 Pro and the Pro Click V2 Vertical arrived this way.
